## 2026-10-25 - Stateful Toggle Button Accessibility
**Learning:** Toggle buttons (like a dark/light theme toggle) that change state visually but do not change the page URL often lack screen reader feedback when their state changes. It is a critical accessibility requirement to manage the `aria-pressed` attribute dynamically via JavaScript to ensure screen readers announce the current state.
**Action:** Always include an initial `aria-pressed` attribute (usually `false`) on stateful toggle buttons and ensure the JavaScript logic handling the toggle event updates this attribute dynamically alongside any visual or data attribute changes. Also, remember to dynamically set the initial `aria-pressed` state on page load based on user preferences (e.g. `window.matchMedia`) to ensure it is accurate before any user interaction.
