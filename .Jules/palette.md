## 2024-06-25 - Implement Roving Tabindex for Accessible Tablists
**Learning:** Proper keyboard navigation for WAI-ARIA tablists requires implementing a roving tabindex. Only the currently active tab should be in the document's tab order (`tabindex="0"`), while unselected tabs should be skipped (`tabindex="-1"`). Arrow keys should handle moving focus and activating adjacent tabs. Additionally, tab panels must be focusable (`tabindex="0"`) to allow keyboard navigation into their content, especially when the panel content lacks its own inherently focusable elements, enabling users to scroll the panel with arrow keys.
**Action:** Always implement arrow-key navigation and roving tabindex when creating custom tab components to ensure they conform to WAI-ARIA best practices and are fully usable by keyboard-only users.
